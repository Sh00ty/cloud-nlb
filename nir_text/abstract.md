## РЕФЕРАТ

Отчёт содержит 78 с., 8 рис., 29 источн.

Ключевые слова: БАЛАНСИРОВКА НАГРУЗКИ, VPP, ОБЛАКО, ОТКАЗОУСТОЙЧИВОСТЬ, CONTROL PLANE, DATA PLANE, HEALTH CHECK, CONSISTENT HASHING, KUBERNETES, CHAOS TESTING.

Объектом исследования являются облачные системы балансировки сетевого трафика на уровнях L3/L4.

Предметом исследования является архитектура, алгоритмы и методы обеспечения отказоустойчивости L3/L4 балансировщика нагрузки в облачной среде.

Цель работы — реализация отказоустойчивого многопользовательского L3/L4 балансировщика нагрузки на базе VPP, адаптированного под нужды облачного провайдера.

В настоящей работе была спроектирована, реализована и протестирована отказоустойчивая система сетевой балансировки нагрузки на базе VPP, в которую входят следующие компоненты: плоскость управления, плоскость данных и подсистема мониторинга состояния клиентских эндпоинтов.

К основным результатам работы относятся:
- анализ существующих решений в области L3/L4 балансировки, выявлено отсутствие полноценных открытых аналогов;
- компонентная архитектура системы с разделением на плоскость управления, плоскость данных и систему проверок состояния;
- плоскость управления с декларативным API, реконсиляцией размещения целевых групп, gRPC API с long-poll и версионированием через etcd;
- децентрализованная система проверок состояния на основе gossip/SWIM и двухуровневого consistent hashing с настраиваемым фактором репликации;
- агент плоскости данных с реконсиляцией целевого состояния и подпиской на health-статусы через CDC;
- методика хаос-тестирования с воспроизводимыми сценариями отказов;
- серия экспериментов, подтвердивших отказоустойчивость разработанной системы.

Область применения - внутренняя инфраструктура облачного провайдера для предоставления сервиса L3/L4 балансировки нагрузки облачным управляемым решениям и конечным пользователям.
